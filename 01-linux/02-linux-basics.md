# Linux Basics

## Пользователь

Мой Linux-пользователь:

storm

Проверка:

whoami

Результат:

storm

## Домашний каталог

Команда:

pwd

Результат:

/home/storm

Символ ~ означает домашний каталог текущего пользователя.

## Просмотр файлов

ls

Подробный просмотр:

ls -la

## Переход в каталог

cd /path

Переход домой:

cd ~

## Основные понятия

root — корень файловой системы Linux

~ — домашний каталог пользователя

. — текущий каталог

.. — родительский каталог
