# Linux Filesystem

Linux имеет единую файловую систему,
начинающуюся с /

Основные каталоги:

/home
    Домашние каталоги пользователей.

/etc
    Конфигурационные файлы.

/var
    Изменяемые данные и логи.

/tmp
    Временные файлы.

/usr
    Программы и библиотеки.

/opt
    Дополнительное программное обеспечение.

/root
    Домашний каталог пользователя root.

Мой домашний каталог:

/home/storm


/
├── home   → пользователи
├── etc    → конфигурация
├── var    → данные/логи
├── tmp    → временные файлы
├── usr    → программы
└── opt    → дополнительное ПО
