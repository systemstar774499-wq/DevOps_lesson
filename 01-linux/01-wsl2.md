# WSL2

## Что это

WSL2 (Windows Subsystem for Linux 2) позволяет запускать
Linux-среду внутри Windows.

В моей лаборатории:

Windows 11 Pro
    ↓
WSL2
    ↓
Ubuntu 26.04 LTS

## Моя конфигурация

CPU: Intel Core i7-12700
Ядра: 12
Потоки: 20
RAM: 16 GB
SSD: 512 GB
HDD: 2 TB

WSL:
Version: 2.7.12.0
Kernel: 6.18.33.2
Ubuntu: 26.04 LTS

## Проверка

wsl --status
wsl -l -v
wsl --version

## Главное

WSL2 позволяет использовать Linux-инструменты
без установки Linux вместо Windows.
