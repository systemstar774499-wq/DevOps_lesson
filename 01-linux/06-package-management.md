# Следующая практика: установка пакета
Теперь хочу, чтобы ты сам установил небольшой полезный инструмент, а не просто прочитал теорию.

Будем использовать tree. Он показывает структуру каталогов:

DevOps_lesson/
├── 01-linux/
│   ├── 01-wsl2.md
│   ├── 02-linux-basics.md
│   └── ...
├── 02-git/
└── 00-roadmap.md

Установка:
sudo apt install tree

После установки проверь:
tree --version

И затем:
tree ~ -L 2

показала содержимое домашнего каталога /home/storm, а он у тебя сейчас пустой:
/home/storm

0 directories, 0 files

Это не означает, что Ubuntu пустая. Системные файлы находятся в других каталогах (/etc, /usr, /var, /home и т. д.).

Давай проверим сам tree

Выполни:
tree --version
Если увидишь версию, например:
tree v2.x.x

значит пакет установлен правильно.

А затем попробуем посмотреть уже реальную структуру Linux:
sudo tree /etc -L 2

Покажет примерно вот так.
├── 01-linux/
│   ├── 01-wsl2.md
│   ├── 02-linux-basics.md
│   └── ...
├── 02-git/
└── 00-roadmap.md

Здесь будет намного больше вывода, поэтому можешь выполнить:

tree /etc -L 2 | head -50
Это покажет только первые 50 строк.

Вот здесь начинается самое интересное: ты установил пакет через APT и сразу используешь его для изучения файловой системы. Это именно тот формат обучения, которого мы придерживаемся: команда → результат → понимаем, что произошло → записываем в конспект.
