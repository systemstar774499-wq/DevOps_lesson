| Команда | Назначение                |
| ------- | ------------------------- |
| `pwd`   | где я нахожусь            |
| `ls`    | список файлов             |
| `cd`    | перейти в каталог         |
| `mkdir` | создать каталог           |
| `touch` | создать файл              |
| `cp`    | копировать                |
| `mv`    | переместить/переименовать |
| `rm`    | удалить                   |
| `cat`   | показать содержимое       |
| `less`  | просмотреть файл          |
| `grep`  | искать текст              |
| `find`  | искать файлы              |
